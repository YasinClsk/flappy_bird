# Flappy Bird Oyunu

Bu proje HTML, CSS ve JavaScript kullanılarak oluşturulmuş basit bir Flappy Bird klonudur.

## Nasıl Oynanır?

- Oyunu başlatmak için SPACE tuşuna basın
- Kuşu zıplatmak için SPACE tuşunu kullanın
- Borulardan kaçının ve mümkün olduğunca yüksek skor elde etmeye çalışın
- Oyun bittiğinde "Tekrar Oyna" butonuna tıklayarak yeniden başlayabilirsiniz

## Özellikler

- Modern ve duyarlı tasarım
- Skor sistemi
- Animasyonlu arka plan
- Yeniden başlatma özelliği

## Teknolojiler

- HTML5
- CSS3
- JavaScript (Vanilla)
